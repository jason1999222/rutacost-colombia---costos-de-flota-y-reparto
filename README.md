# 🚚 RutaCost Colombia - Costos de Flota y Reparto

RutaCost Colombia es un sistema diseñado para la gestión y cálculo eficiente de los costos operativos asociados a flotas de vehículos y rutas de reparto.

## 🚀 Características Principales
- **Módulo de Flota:** Gestión de vehículos y sus gastos asociados.
- **Módulo de Reparto:** Optimización y seguimiento de costos por ruta.
- **Integración con Firebase:** Almacenamiento en tiempo real y autenticación.

## 🛠️ Tecnologías Utilizadas
- [Firebase](https://firebase.google.com/) (Autenticación, Firestore, Hosting, etc.)
- React + Vite
- Node.js

## 📦 Instalación y Configuración Local

Sigue estos pasos para ejecutar el proyecto en tu máquina local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/jason1999222/rutacost-colombia---costos-de-flota-y-reparto.git
   cd rutacost-colombia---costos-de-flota-y-reparto
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Configurar las variables de entorno:**
   - Duplica el archivo `.env.example` y renómbralo a `.env`.
   - Llena los valores en el archivo `.env` con tus credenciales de Firebase.

4. **Ejecutar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

## 📂 Estructura del Proyecto
- `/src`: Código fuente principal de la aplicación.
- `/public`: Archivos estáticos e `index.html`.
- `/assets`: Imágenes, íconos y otros recursos multimedia.
- `/scripts`: Scripts automatizados para tareas de desarrollo.
- `/docs`: Documentación oficial, diagramas e información del proyecto.
